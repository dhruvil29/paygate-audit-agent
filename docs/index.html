PayGate Audit Agent

An agent that audits a checkout before payment — and never touches money without a human saying so.

⚠️ MOCK DATA DEMO — READ FIRST This page runs entirely in your browser on labelled mock checkout data. It has no live PayPal connection, makes no PayPal calls, and moves no money. The PayPal sandbox path in the real project is code-complete but has not been live-tested — no PayPal Developer account exists yet — so nothing here is a live sandbox result. The audit rules below are the same deterministic rules as the project's paygate/audit.py: same input, same verdict, every run.

Try it

Pick a mock checkout, then run the audit. The flagged one is the same data as examples/checkout-flagged.json in the repo; the clean one is examples/checkout-clean.json.

What the audit checks

  • Itemizes every fee and recomputes the total from the line items — stated total vs. computed total.
  • Flags: currency mismatch, total mismatch, missing item data, empty cart, negative amounts.
  • Warns on an unusual fee (one fee line over 30% of the goods subtotal — a documented heuristic, not a PayPal rule) and on risky terms (e.g. "non-refundable", "final sale").
  • BLOCK verdict on any blocking issue — the payment step stops here instead of quietly approving.
  • Human-gated recovery: if a payment fails, PayGate re-checks the order and proposes a retry capture — but every step waits on a separate, explicit human approval, logged in an append-only, hash-chained audit trail. There is no auto-retry and no way to skip the gate. (The retry flow itself is in the CLI, not on this page, because this page never touches money.)
